# Binary Calculator

A comprehensive Binary Calculator web application designed for Computer Organization and Architecture (COA) concepts. This project performs arithmetic, logical, and bit manipulation operations on both Binary Integer and Binary Floating-Point numbers with high accuracy and an intuitive user interface.

## 🚀 Features

### Binary Integer Operations
- Binary Addition
- Binary Subtraction
- Binary Multiplication
- Binary Division
- Increment
- Decrement

### Complement Operations
- 1's Complement
- 2's Complement

### Shift Operations
- Logical Left Shift
- Logical Right Shift
- Arithmetic Left Shift
- Arithmetic Right Shift

### Binary Floating-Point Operations
- Floating-Point Addition
- Floating-Point Subtraction
- Floating-Point Multiplication
- Floating-Point Division

### Additional Features
- Real-time Calculation
- User-Friendly Interface
- Error Handling and Validation
- Fast and Accurate Computation
- Responsive Design

---

## 📌 Project Overview

The Binary Calculator is developed to simplify binary arithmetic and help students understand fundamental concepts of Computer Organization and Architecture.

The calculator supports two separate modes:

### Version 1: Binary Integer Calculator
Handles operations on binary integers including:
- Arithmetic Operations
- Complement Generation
- Shift Operations
- Increment and Decrement

### Version 2: Binary Floating-Point Calculator
Handles operations on binary floating-point numbers including:
- Floating-Point Arithmetic
- Fractional Binary Calculations
- Accurate Binary Conversion and Processing
